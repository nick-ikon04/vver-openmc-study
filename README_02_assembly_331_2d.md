# Скрипт 02 - двовимірна ТВЗ ВВЕР-1000 на 331 позицію

Файли моделі:

- `02_assembly_331_2d.py` - побудова, розрахунок та обробка результатів;
- `assembly_331_parameters.json` - усі змінювані параметри;
- `results/02_assembly_331_2d/runs/` - окремі папки запусків.

## Склад ТВЗ

Повний шестикутник радіуса 10 містить 331 позицію:

```text
1 + 6 + 12 + ... + 60 = 331.
```

Поточна UGD-картограма містить 300 звичайних твелів UO2, 12 твегів
UO2-Gd2O3, 18 напрямних труб і одну центральну вимірювальну трубу.

## Координати

Кожна позиція має цілочислові координати OpenMC HexLattice `(x, alpha)`.
Третя кубічна координата дорівнює `z_hex = -x-alpha`. Позиція належить ТВЗ, якщо

```text
max(|x|, |alpha|, |-x-alpha|) <= 10.
```

Перехід до декартових координат для `orientation="y"`:

```text
X = sqrt(3)/2 * P * x
Y = P * (x/2 + alpha)
```

де `P = 1.275 см` - крок твелів. Нумерація йде рядками згори вниз, у рядку
зліва направо. Повна таблиця міститься у `karta_pozytsii_tvz_331.csv`.

Спеціальні елементи задаються у JSON орбітами шестикратної симетрії. Один seed
автоматично повертається п'ять разів на 60 градусів:

```text
(x, alpha) -> (-alpha, x + alpha).
```

Два seed утворюють 12 твегів, три seed - 18 напрямних труб. Центральна труба
розташована в `(0, 0)`.

## Зовнішні параметри

Через `assembly_331_parameters.json` можна змінювати:

- температури палива, води, оболонки та гелію;
- збагачення U-235 і масову частку Gd2O3;
- концентрацію природного бору в ppm;
- густини матеріалів;
- радіуси палива, оболонки, напрямних і центральної труби;
- крок твелів, розмір ТВЗ і координати спеціальних елементів;
- радіальні й аксіальні граничні умови;
- кількість частинок, поколінь, потоків CPU та seed;
- межі енергетичних груп.

Кожен запуск зберігає параметри у `vykorystani_parametry.json`.

## Запуск

Повний розрахунок:

```bash
python 02_assembly_331_2d.py --config assembly_331_parameters.json
```

Лише геометрія та XML:

```bash
python 02_assembly_331_2d.py --config assembly_331_parameters.json --build-only
```

Повторна обробка готового statepoint:

```bash
python 02_assembly_331_2d.py --process-existing results/02_assembly_331_2d/runs/НАЗВА_ПАПКИ
```

## Вихідні файли

- `karta_pozytsii_tvz_331.csv` - усі позиції та координати;
- `potuzhnist_tveliv_tvz_331.csv` - потужність і реакції кожного твела;
- `karta_vidnosnoi_potuzhnosti_tvz_331.png` - кольорова карта потужності;

- `intehralni_reaktsii_tvz_331.csv` - інтегральні реакції;
- `spektr_neitronnoho_potoku_tvz_331.csv` - спектр потоку;
- `reaktsii_izotopiv_palyva_tvz_331.csv` - реакції U-235, U-238, Gd-155 і Gd-157;
- `pidsumok_rozrakhunku.json` - основні показники та похибки.

Карта нормується на середній енергетичний вихід поділів усіх 312 паливних
позицій. Похибки ненормованих tally беруться безпосередньо з OpenMC. Для
відношень і групових середніх застосовується поширення похибок без міжбінової
коваріації; такі значення позначено як наближені.

## Межі 2D та перехід до 3D

2D достатньо для `k_inf`, радіальної карти потужності, порівняння складів,
температурних і борних ефектів, впливу твегів та підготовки групових констант.

2D не описує торцеві витоки, аксіальний профіль потужності, частково введені
стрижні СКЗ, зміну температури й густини за висотою, дистанціювальні решітки та
аксіальне вигоряння.

Для 3D висота ділиться на аксіальні шари з окремими матеріалами й температурами.
На фізичних верхній і нижній межах установлюється `vacuum`. Потужність
накопичується спільним фільтром «номер твела x аксіальний шар», а поглинальні
стрижні додаються лише в ті шари напрямних каналів, куди вони введені.
